## 现在

- **shirakawafm.github.io** — 手写的个人站点，没有框架、没有构建、没有第三方请求。

## 我怎么做东西

1. **先问能不能不要。** 能少一个依赖、少一个权限、少一层抽象，就先减掉。
2. **假设要能被验证。** 动手之前先想清楚：如果这个判断错了，我多久会知道。
3. **动效服务于理解。** 只动 `transform` 和 `opacity`，不劫持滚动，默认尊重 `prefers-reduced-motion`。
4. **写下来。** 决定、代价、失败的原因，都值得留档；否则下次会再犯一遍。

## 在意的事

- **界面的秩序**：字号、字距、留白，比配色更能决定一个页面有没有质感。
- **工具的手感**：启动速度、键盘操作、出错时的提示，比功能数量更重要。
- **影像的节奏**：剪辑点、声音、字幕出现的那半秒，决定了它是"视频"还是"作品"。
